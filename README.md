# Photo Sifer

一个基于 Flask 的本地照片快速筛选工具，支持键盘、触摸滑动和鼠标点击操作，帮助你高效地从大量照片中挑选出想要的图片。

## 功能特性

- **快速筛选**：将照片标记为 YES（保留）或 NO（排除），自动分类到不同文件夹
- **多种操作方式**：
  - 键盘：`←` 左箭头（NO） / `→` 右箭头（YES） / `Ctrl+Z` 撤销
  - 触摸滑动：左滑标记 NO，右滑标记 YES
  - 鼠标点击：点击左半部分 NO，右半部分 YES
  - 鼠标拖拽：左右拖拽超过阈值即可标记
- **图片预览优化**：自动生成缩略图缓存，预加载后续图片，流畅浏览
- **进度追踪**：实时显示处理进度、预计剩余时间
- **撤销支持**：支持撤销上一次的分类操作
- **响应式设计**：适配桌面端和移动端

## 项目结构

```
PhotoSifter/
├── app.py              # Flask 后端服务
├── templates/
│   └── index.html      # 前端页面
├── photos/             # 待筛选的照片目录
├── yes/                # 标记为 YES 的照片（自动创建）
├── no/                 # 标记为 NO 的照片（自动创建）
└── .cache/             # 图片预览缓存（自动创建）
```

## 安装与运行

### 环境要求

- Python 3.x
- Flask
- Pillow

### 安装依赖

```bash
pip install flask pillow
```

### 启动服务

```bash
python app.py
```

服务默认运行在 `http://127.0.0.1:5000`

## 使用步骤

1. 将需要筛选的照片放入 `photos/` 目录
2. 运行 `python app.py` 启动服务
3. 打开浏览器访问 `http://127.0.0.1:5000`
4. 使用键盘、触摸或鼠标操作快速筛选照片：
   - **YES**：保留该照片 → 移动到 `yes/` 文件夹
   - **NO**：排除该照片 → 移动到 `no/` 文件夹
5. 筛选完成后，在 `yes/` 和 `no/` 文件夹中查看分类结果

## 支持格式

- `.jpg` / `.jpeg`
- `.png`
- `.gif`
- `.webp`

## 技术栈

- **后端**：Flask + Pillow（图像处理）
- **前端**：原生 HTML / CSS / JavaScript
- **缓存**：本地文件缓存 + 浏览器内存预加载
